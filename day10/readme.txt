
1.浅拷贝 VS 深拷贝
    浅拷贝: 只会对外层对象进行拷贝
        list1:copy()
        list1[:]
        list(list1)
        copy.copy(list1)

    深拷贝: 不光拷贝外层对象,其中的内层对象也会进行拷贝

    特殊情况:
        不可变类型不能进行拷贝
        元组变量如果只包含不可变类型对象,则不能对其进行拷贝(都不能进行浅拷贝和深拷贝);
        元组变量如果还包含可变类型对象,则可以对其进行拷贝(浅拷贝和深拷贝都可以).

        __iter__

3.生成器
    是一种迭代器,按需生成数据,不会将数据一次性都生成放到内层中
    即是一个迭代器对象,也是可迭代的
    创建生成器对象
        推导式 ()
        类似标准函数
            通过 yield 进行返回
    如果想要获取生成器函数返回值
        需要对 StopIteration 异常进行捕获,获取到的异常描述信息,就是生成器函数通过 return 的返回值(不是通过 yield 返回的值)
    如果想要对生成器发送值
        需要使用 send(值) 的方式将发生的值作为 yield 表示的返回值
    唤醒生成器的两种方式
        next(生成器对象)
        生成器对象.send()
        如果通过 send 第一次唤醒生成器,那么参数值必须是 None

4.命名空间
    是名称到对象的映射,大多数命名空间都是用 Python 字典实现,各个命名空间是独立的,没有任何关系
    在不同时刻创建,且拥有不同的生命周期
    常用的命名空间
        内置, 全局(模块), 局部(函数), 类, 闭包...

5.闭包
    函数的嵌套定义
    在一个函数中,可以访问另一个函数的局部变量
    外层函数的返回值是内部函数的对象

    闭包底层将外层函数的局部变量的生命周期延长了,和内层函数进行绑定
    通过 __closure__ 属性可以知道内层函数访问了外层函数的哪些局部变量

7.装饰器
    装饰器允许在不修改原有函数代码的基础上,动态地增加或修改函数的功能.
    装饰器本质上是一个接收函数作为输入,并返回一个新的包装过后的函数的对象
    可以对功能进行扩展,对原函数代码的修改操作进行关闭
    语法
        def decorator(func):
            def inner(参数):
                # 添加功能
                func(参数)
                # 添加功能
            return inner

    说明
        decorator 是一个装饰器函数,它接受一个函数 func 作为参数
        并返回一个内部函数对象 inner
        在 inner 函数内部,可以执行一些额外添加的操作,然后调用原始函数 func,并返回其结果

    实现方式
        闭包实现装饰器
        使用装饰器
            装饰器函数(原有函数名)(原有函数参数列表)
            装饰器语法糖: 在原函数上添加 @实现的装饰器函数名

    多层装饰器
        先装饰,后调用
        从下往上进行装饰,从上至下进行调用（嵌套顺序）
        多个装饰器装饰过程:
            离原函数最近的装饰器先装饰,然后外面的装饰器再进行装饰
            离原函数最远的装饰器先调用,然后内层的装饰器再进行调用

    带参数的装饰器

    类装饰器
        包含 __call__() 方法的类,接受函数作为参数,并返回新的函数
        在 Python 中,一个类定义了 __call__ 方法后,该类的实例可以像函数一样被调用. 这种对象被称为可调用对象(仿函数)
        语法
            class 装饰器名:
                def __init__(self, f):
                    self.f = f

                def __call__(self, x):
                    x = abs(x)
                    return self.f(x)

            @装饰器名
            def func(x):
                函数功能

            print(func(参数))

        注意:类装饰器也会可以存在多层类装饰器

        类装饰器区分:
            无参类装饰器:
                __init__(self, func): 接收被装饰函数对象
                __call__(self, *args, **kwargs): 调用原函数时执行
            有参类装饰器:
                __init__(self, 装饰器参数): 接收装饰器参数
                __call__(self, func): 接收被装饰函数对象
