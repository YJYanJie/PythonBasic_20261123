
1.语法错误和异常
    语法错误: 解释器不能正确的解释我的程序
    异常: 解释器能够正常解释程序,但是运行的过程报错了

2.异常处理
    对异常进行处理,并不是将错误规避了,而是当程序运行时,出现错误的时候能够提供解决方案,不终止程序,可以让程序继续执行
    语法
        try:
            可能发生异常的代码
        except:
            如果发生了异常,对异常进行处理的代码

    说明
        如果没有发生异常,程序会忽略 except 中的代码,继续向下执行
        如果发生了异常,会忽略 try 中剩余代码,执行 except 中的代码, except 中的代码执行完毕后,会继续执行程序

3.异常处理底层原理
    当程序执行的过程中,发生了异常,底层会创建一个异常类型的对象,并向上抛出
    except 可以捕获异常对象,可以在 except 后面指定捕获异常的具体类型
    语法:
        try:
            可能发生异常的代码
        except 异常类型1 as 变量1:
            异常处理语句1
        except 异常类型2 as 变量2:
            异常处理语句2
        except (异常类型3,异常类型4) as 变量3:
            异常处理语句3
        except:
            捕获处理所有类型异常

    说明:
        如果没有发生异常,程序会忽略所有的 except 中的代码,继续向下执行
        如果发生了异常,会忽略 try 中剩余代码,根据异常类型进行匹配,匹配到相应的 except 并执行其中的代码
        如果发生了异常,且异常类型无法与任何的 except 匹配,异常将会向外传递
        一个 except 可以同时处理多个异常,将这些异常放在一个元组中
        最后一个 except 可以忽略异常类型,它将被作为通配符使用

4.else
    try:
        可能发生异常的代码
    except:
        对异常进行处理的代码
    else:
        如果try中的代码没有发生异常,将会执行 else 中的代码

    从执行效果来说,将代码放到 else 中和直接放到 try 中是一样的

5.finally
    语法
        try:
            可能发生异常的代码
        except 异常类型1 as 变量1:
        except 异常类型2 as 变量2:
        except (异常类型3,异常类型4) as 变量3:
        except:
        else:
            try块中的代码正常执行，没有发生异常后执行的代码
        finally:
            不管是否会发生异常,都会执行的代码

    说明
        如果从执行效果上说,大部分场景中,将代码放到 finally 语句和放到 try-except 外效果是一样的
        finally 语句块是 try-except 结构的一部分,它确保了无论 try 块中是否发生了异常,也无论 except 块是否被执行,finally 块中的代码都会被执行
        直接放在 try-except 结构外面的代码只会在 try-except 结构正常执行完毕后才会执行,如果在 try 块中出现异常且没有被 except 块捕获,
            或者在 except 块中出现了新的异常导致程序终止,那么放在 try-except 外的这部分代码将不会被执行
        所以,一般在 finally 块中的代码,大多数是对资源的释放以及一些连接的关闭操作等.

9.with关键字
    封装了 try-except-finally 编码范式,提供了一种简洁的方式来确保资源的正确获取和释放,同时处理可能发生的异常,提高了易用性
    语法
        with expression as variable

    说明:
        表达式:对象或者是函数的调用,需要返回一个上下文管理器对象(__enter__ 和 __exit__)
        变量:用于存储 expression 的 __enter__ 方法的返回值(一般返回的是对象本身 self)

    描述:
        使用 with 关键字时,系统会自动调用 f.close() 方法, with 的作用等效于 try finally 语句
        当执行 with 语句时,会调用 expression 对象的 __enter__ 方法.
        __enter__ 方法的返回值可以被存储在 variable 中(如果有),以供 with 代码块中使用.
        然后执行 with 语句内部的代码块
        无论在代码块中是否发生异常,都会调用 expression 对象的 __exit__ 方法,以确保资源的释放或清理工作
            类似于 try-except-finally 中的 finally 子句.
