2.面向对象相关的概念
    对象
        万物皆对象,在自然界中只要是客观存在的事物都是对象

    类
        类是对大量对象共性的抽象
            有什么    -------      属性
            能做什么  -------      方法
        类是创建对象的模板
        类是客观事物在人脑中的主观反应

3.定义类的语法以及类中成员
    class Person:
        # 属性 --- 类属性(所有类创建出来的对象共用)
        home = "earth"

        # 方法
        def __init__(self, name, age):
            # 属性 --- 实例属性(每个类创建出来的对象独有)
            self.name = name
            self.age = age

        def eat(self):
            print("eating")

        def drink(self):
            print("drinking")

    说明
        类是对大量对象共性的抽象,其中主要定义了属性和方法
        class 是类的关键字,主要用来标记定义类
        Person 是当前类的类名, 类名主要是大驼峰命名
        类名后的 : 必须要加
        缩进后的内容是类体
        属性
            类属性:   所有类创建出来的对象(实例)共用
            实例属性: 每个类创建出来的对象独有
        方法
            实例方法

4.类的操作
    成员引用
        直接通过类名访问类中的成员

    实例化
        通过类,创建对象(创建一个类的实例),来访问类|对象的成员

5.__init__方法
    在定义类的时候,__init__方法不是必须的
    如果没有显式提供__init__方法,系统底层会提供一个默认的无参的__init__方法
    在一些资料中,将__init__方法称之为构造函数,其实这种说法不严谨
    因为构造函数主要功能是帮助我们创建对象的,在python语言中,真正对象的创建操作是一个叫__new__的方法完成
    只不过__new__创建完对象之后,会将创建好的对象交给__init__
    在__init__方法中,主要完成的功能是对新创建的对象进行一些初始化操作,例如:给对象添加属性(实例)以及给属性赋值

    如果显式的提供了__init__方法,在创建对象的时候,传递的参数个数,必须和__init__中声明的形参个数一致(不包括self)

6.self
    self代表类的实例本身
    通过self可以在类中调用类的实例属性和实例方法

7.属性
    类属性
        属于类的,可以让类创建出来所有对象共享
        可以通过 类名.属性名 的方式进行添加,修改,访问
        也可以通过 实例名.属性名 的方式进行访问
        通过 实例名.属性名 的方式进行添加的话,创建的实例属性

    实例属性
        也叫实例变量,在类的__init__方法中定义的属性,通过self.属性名定义
        每个类创建出来的对象独有
        通过 实例名.属性名 进行访问,添加,修改

8.方法
    实例方法
        实例方法在类中定义,第一个参数为self,代表实例本身
        实例方法能被实例对象调用, 也可以通过 类名.实例方法名(实例对象) 调用实例方法
        可以访问实例属性, 类属性, 类方法

    类方法
        在类中通过 @classmethod 定义,第一个参数为 cls,代表类本身
        类方法可以被类和实例对象调用
        可以访问类属性
        在不创建实例的情况下调用,通过类名直接调用,适合一些和类整体相关的操作

    静态方法
        在类中通过 @staticmethod 定义
        不访问实例属性或类属性,只依赖于传入的参数
        可以通过类名或者实例调用,但它不会访问类或实例的内部信息,更像是一个工具函数
        只是为了方便组织代码,将它放在了类里面

    在类外定义方法
        可以将一个函数对象赋值给一个类内局部变量
        注意:类外定义的这个方法,第一个参数必须是 self

    魔法方法
        方法名中有两个前缀下划线和两个后缀下划线的方法为特殊方法,也叫魔法方法.
        这些方法会在进行特定的操作时自动被调用
        常见的魔法方法:
            __new__: 对象实例化时第一个调用的方法
            __init__: 类的初始化方法
            __del__: 对象的销毁器,当对象被垃圾回收时的行为. 使用 del 对象名 时不会主动调用 __del__, 除非此时引用计数==0
            __str__: 对类的实例调用 str() 方法时的行为
            __repr__: 类的实例调用 repr() 方法时的行为
            __getattribute__: 属性访问拦截器,定义了属性被访问前的操作

            str() 和 repr() 最主要的差别在于目标用户.
                repr() 的作用是产生机器可读的输出(大部分情况下,其输出可以作为有效的Python代码)
                str() 是产生人类可读的输出.
