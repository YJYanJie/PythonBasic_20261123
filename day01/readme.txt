4.计算机语言的执行方式
    编译型语言
        源文件 --> 编译器 --> 可执行程序 .exe --> 计算机能够识别的机器指令
        例如：C、C++
    解释型语言
        源文件 --> 解释器 --> 计算机能够识别的机器指令
        例如：Python、JavaScript

    注意：虽然将 Python 归类为解释器语言，但其实它的底层运行的时候，是先编译再解释的
        源文件.py --> 解释器（编译器 --> 字节码文件.pyc【默认是隐式生成的】）

6.注释
    对代码的解释说明
    注释在程序执行的过程中是不起任何作用的
    注释的主要使用场景
        提升代码的可读性
        屏蔽掉暂时不需要的代码
        定位程序中出错的位置

7.注释的分类
    单行注释
        # 被注释的内容
    多行注释
        以三个引号引号开始，以三个引号引号结束
        引号可以是单引号、可以是双引号
        '''被注释的内容 '''
        """被注释的内容 """

8.变量
    在程序执行的过程中，其值可以改变的量
    声明赋值变量
        变量名 = 变量值

9.常量
    在程序执行的过程中，其值不会改变的量
    比如π
    如果是常量，定义的语法和变量是一样的
    可以通过名字大写进行区分    PI = 3.14

10.进制
    二进制 -- 0b
    八进制 -- 0o
    十六进制 -- 0x

11.三个函数
    type(对象):获取对象的类型
    isinstance(对象, 类型):判断对象是否是某个类型
    id(对象):获取对象在内存中的地址

12.小整数池
    在CPython中,对于[-5,256]之间的数据是提前创建好对象,放到小整数池中
    如果在程序中,如果有变量指向这些对象,不需要新创建,直接指向即可
