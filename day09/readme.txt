
1. 不带包的模块导入
    全局导入
        导入模块的所有成员,通过 模块名.成员名
        语法:
            import 模块名 [as 别名]
        访问:
            模块名.成员名

    局部导入_1
        语法:
            from 模块名 import 成员1[as 别名], 成员名2[as 成员]
        说明:
            指定导入模块的部分成员,只能使用其导入的成员,未导入的成员无法使用
            如果多个模块中存在重名成员,后一次的导入会覆盖前一次导入
        访问:
            直接通过成员名的方式访问

    局部导入_2
        语法:
            from 模块名 import *
        说明:
            导入模块中所有不以单下划线开头的成员
        访问:
            通过成员名的方式访问

2.模块搜索顺序
    当导入一个模块时,会按照以下顺序进行查找
        当前目录
        python 环境变量的目录
        包含标准 python 模块以及这些模块所依赖的任何 extension module 的目录
    可以通过 sys.path 查看模块搜索顺序

3.__all__属性
    前提: 在使用 from 模块名 import * 的时候生效
    说明: 在被导入的模块中,通过 __all__ 属性声明,哪些成员可以被导入
         就算是当前成员以 _开头,如果声明在 __all__ 中,也可以被外部访问

4.__name__属性
    __name__是一个特殊的内置变量
    当一个 Python 文件被直接运行时,该文件的 __name__ 属性值为 "__main__"
    当一个 Python 文件作为模块被导入时,__name__ 属性会被设置为该模块的名称(即文件名,不包含 .py 后缀)
    如果在导入其他模块的时候,不需要被导入的模块的测试代码被执行,那么可以在被导入模块中加如下分支判断
        if __name__="__main__":
            执行测试语句

5.dir函数
    dir()是一个内置函数,主要用于列出对象的属性和方法,或者列出当前作用域中定义的名称,并以一个字符串列表的形式返回

6.带包的模块导入
    包: 带有 __init__.py 的文件夹
    模块的导入最终都是导入模块中的成员

    全局导入
        语法:
            import 包名.模块名 [as 别名]
        说明:
            导入包中模块的所有成员
            如果import导入的时候，最后一项是包，python会进行限制，不能将包下的所有模块的所有成员都导入
            需要在被导入的包的__init__.py文件中，加入导入哪些模块的限制。
            一般在__init__.py中使用相对路径的导入方式
        访问:
            包名.模块名.成员名 或者 别名.成员名

    局部导入--1
        语法:
            from 包名 import 模块名 [as 别名]
        说明:
            导入包中某一个模块的所有成员
        访问:
            模块名.成员名

    局部导入--2
        语法:
            from 包名.模块名 import 成员名 [as 别名]
        说明:
            导入包中某一个模块的某一个成员
        访问:
            成员名


    局部导入--3
        语法:
            from 包名.模块名 import *
        说明:
            导入包中某一个模块的所有成员(除了 _ 开头的成员名)
        访问:
            成员名

    局部导入--4
        语法:
            from 包名 import *
        说明:
            导入包中的所有模块
        访问:
            模块名.成员名
        注意:
            必须在包的 __init.py 中通过 __all__ 指定哪些模块以被导入

7.打包
    pip install setuptools
    在需要打包的文件夹外添加 setup.py, 内容如下

        from distutils.core import setup

        setup(
            name="graphic", # 需要打包的名字
            version="1.0",  # 版本
            py_modules=["graphic.circle", "graphic.rectangle"],  # 需要打包的模块
        )

    与 setup.py 同级目录下,进入终端中(注意,该终端使用的python环境需要和你程序的python环境一致)
    执行: python setup.py build   进行打包,会在同级目录中出现 build 文件夹,里面存放的是打包好的文件
    执行: python setup.py sdist 进行压缩,得到 dist 文件夹下的压缩包
    将自己打好的包进行安装.
        方式1: pip install path_to_your_package/dist/your_package_name-0.1.tar.gz
        方式2: PyCharm 通过 Python Packages 从磁盘中进行安装
    最后可以将相关文件删除即可(setup.py, build, dist, graphic, graphic.egg-info)

8.浅拷贝VS深拷贝
    浅拷贝 拷贝父对象,不会拷贝对象内部中的子对象.拷贝后只有第一层是独立的
    深拷贝 完全拷贝了父对象及其子对象.拷贝后所有层都是独立的

    可变容器类型,可以进行深拷贝
    非容器类型（如数字、字符串、和其他“原子”类型的对象）无法拷贝
    元组变量如果只包含原子类型对象，则不能对其深拷贝
    但是若元组变量包含了可变类型对象,则可以对其进行深拷贝操作

8.相关概念对比
    遍历:将数据一个个取出
    循环:重复执行一段代码,是实现遍历的一种方式
    迭代:也是实现遍历的一种方式,底层是迭代器

    for循环底层其实就是迭代器

    Iterable:可迭代对象
        能直接使用 for 循环进行遍历, 底层实现了 __iter__,当调用 iter() 方法时会被调用

    Iterator:迭代器
        底层实现了 __iter__, 当调用 iter() 方法时会被调用
        底层实现了 __next__, 当调用 next() 方法时会被调用
