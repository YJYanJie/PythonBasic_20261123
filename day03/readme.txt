2. match...case分支
    语法:
        match x:
            case a:
                语句1
            case b:
                语句2
            case _:
                语句3

    说明:
        match 是关键字
        x 是一个表达式,后面的 : 必须加
        如果和 a 匹配上了,执行语句 1 的内容
        如果和 b 匹配上了,执行语句 2 的内容
        如果a,b都没有匹配上,执行语句 3 的内容

4.循环
    当满足某个条件的时候,重复的执行一段代码
    while
        语法
            while 条件表达式:
                重复执行的代码(循环体)
            else:
                当 while 表达式结果为 False 时会执行 else 中的语句
        说明
            先判断条件是否成立,如果条件成立就执行一次循环体;然后再判断条件是否成立,如果成立,继续执行循环体,直至循环体不成立为止,
            才会结束循环,执行循环下面的其他语句. 判断条件可以是任何表达式,任何非零,非空(null)的值均为true.执行语句可以是单个语句或者代码块
            如果条件表达式一直成立,那就是无限循环,也叫做死循环..
            注意：为了避免死循环，在循环体中别忘了改变影响循环条件的变量

    for
        语法
            for 临时变量 in 可迭代对象:
                循环体
            else:
                循环正常结束的时候,执行的代码

        说明
            for, in 是关键字
            首先先判断可迭代对象中是否有下一个元素
            如果有,则将元素取出,赋值给临时变量
            继续判断是否有下一个元素,直至可迭代对象中没有元素了,循环结束

    如果明确循环的对象或者循环次数使用for循环
    如果不明确循环的对象或者循环次数使用while循环

5.continue & break
    continue: 跳过当前正在进行的循环，继续下一次循环
    break: 跳出当前循环
    return: 跳出当前函数
    pass: 占位语句

6.序列
    容器中元素有序(放进去的顺序和取出的顺序一致)
    每个元素都有自己对应的下标(索引)      左:0开始递增      右:-1 开始递减
    可以通过下标获取操作序列中的元素

7.列表 list
    可变
    有序
    元素可重复
    可以存放不同类型的数据
    使用[]创建列表对象
